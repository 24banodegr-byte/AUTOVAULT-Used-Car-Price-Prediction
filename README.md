# 🚗 AUTOVAULT — Used Car Price Prediction

An interactive Machine Learning project that estimates the selling price of used cars using car-related features.

## ✨ Features
- Used car price prediction through a Gradio interface
- Input features such as year, kilometres driven, fuel type, transmission and ownership
- Regression model comparison
- Hypothesis testing and statistical analysis
- Data visualisation and model evaluation

## 🤖 Machine Learning
- Random Forest Regressor
- Extra Trees Regressor
- Gradient Boosting Regressor

Models are evaluated using MAE, RMSE and R² score.

## 📊 Hypothesis Testing
- One-Way ANOVA
- Kruskal-Wallis Test
- Levene's Test
- Spearman Correlation

## 🛠️ Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- SciPy
- Matplotlib
- Gradio

## 🚀 Getting Started

Install the required libraries:

```bash
pip install -r requirements.txt
```

Open `AUTOVAULT.ipynb` in Google Colab and run the notebook cells in order.

- Used car buyers
- Used car sellers
- Car dealers
